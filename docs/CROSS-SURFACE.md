# Visual Studio, VS Code, and Copilot CLI

The course uses Visual Studio for the primary walkthrough. The durable workflow
is the same on every supported surface.

| Task | Visual Studio | VS Code | Copilot CLI |
|---|---|---|---|
| Start agent | Right-click **Modernize** or `@Modernize` | Copilot Chat `@upgrade` | `@upgrade` |
| Select Guided Mode | State it in chat | State it in chat | State it in chat |
| Review artifacts | Solution Explorer/editor | Explorer/editor | Editor or terminal |
| Review diffs | Git Changes | Source Control | `git diff` |
| Validate | Test Explorer/terminal | Testing/terminal | Terminal |

The assessment, `upgrade-options.md`, `plan.md`, `tasks.md`, per-task state,
Git commits, tests, and checkpoints remain identical. UI labels and approval
prompts can differ. Follow expected artifacts and validation criteria rather
than screenshots.
