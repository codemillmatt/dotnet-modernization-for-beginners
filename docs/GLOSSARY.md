# Glossary

| Term | Meaning in this course |
|---|---|
| Acceptance gate | Evidence that must pass before a task is accepted |
| Assessment | Evidence-gathering stage; it does not change application code |
| Behavioral change | Code compiles but observable behavior can differ |
| Binary incompatibility | Existing compiled binary cannot use the target API contract |
| Characterization test | Test that records important current behavior before change |
| Checkpoint | Immutable known-good course state used for compare, reset, or resume |
| EF migration | Versioned schema change generated and reviewed with EF Core |
| Execution | Agent applies approved plan tasks under human review |
| Guided Mode | Agent pauses at stage boundaries for review |
| Managed identity | Microsoft Entra identity whose credential lifecycle Azure manages |
| Plan | Ordered, dependency-aware tasks, gates, risks, and rollback points |
| Rollback gate | Condition that triggers restoring the prior checkpoint |
| Source incompatibility | Source must change to compile against the target |
| `what-if` | Azure deployment preview of proposed infrastructure changes |
