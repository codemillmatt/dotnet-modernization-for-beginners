# Reading an example assessment

`simple-legacy-app/` preserves a recorded assessment of the introductory console sample. Its fields, paths, counts, and suggested changes describe that recording. They are not a current product schema or expected BookCatalog result.

These files previously lived at `.github/upgrades/scenarios/dotnet-version-upgrade/`. They are reference material, not an active upgrade. Historical GitHub links to a specific commit remain unchanged.

Run a new assessment on your own solution. Locate its `.github/upgrades/{scenarioId}/assessment.md` through the agent and confirm the report identifies the solution you opened. Do not copy this example into your live scenario.
