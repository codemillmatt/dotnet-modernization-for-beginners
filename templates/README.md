# Templates

Copy these into your own repository and fill them in as you go. Each one has a worked
example row so you can see the level of detail that makes it useful.

| Template | Use it in | What it's for |
|---|---|---|
| [Assessment worksheet](assessment-worksheet.md) | Chapter 01 | Turning findings into decisions |
| [Upgrade plan](upgrade-plan.md) | Chapter 02 | Recording what you changed about the agent's plan and why |
| [Reviewed change log](change-log.md) | Chapter 03 | What each task changed and how you validated it |
| [Risk register](risk-register.md) | Chapters 01–03 | Risks with owners and triggers, not just a list of worries |
| [Cloud architecture decision record](cloud-architecture-decision.md) | Chapters 05–06 | The Azure decisions you made and the gaps you accepted |
| [Transfer plan](transfer-plan.md) | Chapter 07 | Applying all of it to your own application |

Fill these in while you work, not afterward. A change log reconstructed from memory is a
document nobody can rely on.
